# ArquitecturaCoreV1 - version final

## Contributing 
1. **Fork the repository** 📚
2. **Clone your fork (Only the dev Branch)**
   ```bash
   git clone --branch dev https://github.com/
   ```
3. **Navigate into the project directory**
   ```bash
   cd 
   ```
4. **Create a new branch** 🌿
   ```bash
   git checkout -b feature/your-feature-name
   ```

5. **Navigate to the backend and frontend directories**
   ```bash
   cd 

6. **Set up environment variables**
   - Create a `.env` using `.env.example` as a reference.

7. **Run the backend server** (Port: `8000`)

9. **Make your changes** ✨
10. **Commit your changes** 💾
   ```bash
   git commit -m "Add: A meaningful commit message"
   ```
11. **Push to your branch** 👤
   ```bash
   git push origin feature/your-feature-name
   ```
12. **Create a Pull Request** 🛠️
